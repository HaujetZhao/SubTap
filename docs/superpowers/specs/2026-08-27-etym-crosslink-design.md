# 词源交叉引用跳转（方案 A：原位替换）设计

日期：2026-08-27

## 需求

右栏词卡展开的词源词条内，词典自带交叉引用死链（`<a href="/ciyuan/目标词">`）。现将其拦截并利用：点击即在当前展开体内原位加载目标词的词源词条。

## 设计

- 改动仅限 `src/components/WordPanel.vue`（+ 少量样式），纯逻辑层不动。
- 词源展开体的点击 handler：取 `event.target.closest('a')`；href 以 `/ciyuan/` 开头 → 解码取目标词，`lookupEtymology` 查词条，展开体原位替换为目标词条，顶部加「← 返回 原词」返回链；非词源链照旧仅 prevent 导航。
- 返回链只记一层（上一词），不做历史栈。
- 查无词条：静默不响应。
- 跳转查询结果写回 `etym` 缓存，复用免重查。
- 换句时随 `openWord` 复位一并清空跳转态。

## 验收（用户手动）

1. 展开一个含交叉链接的词源，点链接 → 原位变目标词条，顶部有返回链，点返回回到原词。
2. 非词源链接点击不导航。
3. 查无的目标词点击无反应。
4. 换句后再展开，从头显示该词自己的词源。
